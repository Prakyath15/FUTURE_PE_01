# FUTURE_PE_01 — AI Website Copy Generator for Local Businesses

## Project Overview

This project was completed as part of the **Future Interns Prompt Engineering Internship**.

The objective of this task is to create an AI-powered website copy generation workflow for a local business using structured prompts.

## Business

**Business Name:** Zen Cafe
**Business Type:** Cafe
**Location:** Mangalore

### Target Audience

* Students
* Young adults
* Families
* Local customers

### Main Services

* Dine-In
* Takeaway
* Food & Beverages

### Food Categories

* Pizza
* Pasta
* Sandwiches
* Chinese and fast food
* Desserts
* Fresh juices

### Brand Tone

Friendly, welcoming, modern, and simple.

## Prompt System

The project uses separate structured prompts for three major website sections:

1. **Homepage Prompt**

   * Hero section
   * Value proposition
   * About section
   * Featured offerings
   * Why Choose Us
   * Final CTA

2. **Services Prompt**

   * Dine-In
   * Takeaway
   * Food & Beverages
   * Food categories
   * Customer benefits
   * Services CTA

3. **CTA Prompt**

   * Main CTA
   * Supporting text
   * Primary CTA
   * Secondary CTA
   * Local CTA
   * Gentle urgency CTA

## Prompt Logic

The prompts follow a structured workflow:

**Business Information → Target Audience → Website Goal → Brand Tone → Content Requirements → Constraints → Output Format**

This structure helps generate consistent, simple, persuasive, and website-ready content while reducing unsupported claims.

## Tools Used

* ChatGPT — Prompt creation and content generation
* GitHub — Documentation and project delivery

## Project Deliverables

* Homepage prompt and generated output
* Services prompt and generated output
* CTA prompt and generated output
* Final website copy

## Task Objective

The completed project demonstrates prompt engineering for web content, website copywriting, conversion-focused messaging, client requirement understanding, and an AI content workflow.

## Disclaimer

The generated content is created for the internship task and is based on the business information provided for this project. Unsupported claims such as awards, ratings, prices, discounts, or special offers were intentionally avoided.
